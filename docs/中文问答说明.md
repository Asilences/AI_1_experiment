# 中文电影问答与受控验收

中文入口支持一部电影的一项事实：导演 P57、类型 P136、制片国家 P495、原始语言 P364。可使用中文片名、片库中已有的别名、原文片名或电影 QID，例如 `《盗梦空间》的导演是谁？`、`Inception 的原始语言是什么？`。能否回答取决于所用冻结片库是否包含对应电影与事实。片名对应多个版本时，需要补充年份或 QID。

中文适配器在本地识别电影和四类意图，将问题改写为原有英文规范问句。A0 继续使用已有关系分类器和图谱查询；神经系统继续使用原有英文模型、图谱前缀和生成流程。适配器不查询答案事实，不把标准答案交给预测器，不重新训练多语言模型。英文问题继续沿用原实验路径。

回答优先显示已存储的中文实体标签；缺少中文标签时保留原名，再缺失时显示 QID。中文句子中出现英文人名或语言名属于元数据回退，不表示完成了中文名称翻译。中文页面显示的事实证据来自原有检索或图谱查询；神经系统仍可能生成错误或漏答。

可选的 `kgqa/locales/zh_entities.json` 补充已记录来源的中文展示名和别名；加载时同时核对实体 QID 与冻结英文标签，避免把同一 QID 的其他测试实体误译。展示目录不修改冻结事实、答案 ID 或模型权重。验收分别记录冻结元数据中文标签覆盖与实际展示名覆盖，并对展示目录记录 SHA-256。

主演、上映日期、剧情、预算等超出范围的问题，以及多电影、多关系、否定排除查询，会给出中文说明。未知片名和存在歧义的片名也会提示澄清。这是限定范围内的中文问答入口，不代表任意自然语言闲聊或所有中文表达都能被正确处理。

## 与原实验的关系

已完成的 5000 部电影英文训练、原始验证选模和冻结逐题结果保持独立。中文功能复用已训练资产，不能将新增中文验收数字改写成原神经实验的指标，也不能据此声称完成中文模型训练或开放域泛化。

`benchmarks/run_chinese_acceptance.py` 是单独命名的 **中文受控接口验收**。默认在已有 valid 和 test 划分中，各按电影 ID 字典序选 10 部具有中文标签且四类事实完整的电影。每部电影的四种意图各有规范问句、改写问句、混合片名问句，合计 240 个正例；另有 20 个范围外或未知片名负例。混合片名使用已有 `question_title`，其本身可能是中文。v2 对所有具有 `release_year` 的正例统一在片名外补充年份。选择规则只查看片库元数据和事实完整性，不根据适配器或模型预测成败挑题。

首次 v1 诊断中，232/240 个正例回答匹配，20/20 个负例正确拒答；另外 8 个正例都使用未限定版本的《美國隊長》，系统正确提示 1990/2011 年版本歧义。这是题目把歧义输入当作可回答正例的规格问题，不是系统应强行选择版本。v1 同时使用了与训练资产不同的 scikit-learn 1.5.1，并出现版本警告。原结果保留在 `verification/2026-10-30/chinese_qa`。v2 属于看到诊断后的公开协议修订：对所有有年份的正例统一补充年份，在隔离的 scikit-learn 1.6.1 CPU 环境重跑，不修改适配器来强行回答歧义输入，也不更换电影来筛掉失败。结果记录 v1 原始题目、脚本和汇总 SHA-256。v2 不能称为独立自然语料上的再次验证。

这些电影 ID 与训练电影不重合，但回答所需图谱对系统可见。题目由固定人工模板生成，未独立收集自然中文问题；因此该验收检查确定范围的输入归一化、实际 A0 接入、答案实体和拒答行为，不能估计任意中文表达上的准确率。没有中文标题、事实不完整的电影不在这组默认正例中；文档和结果必须同时保留这一限制。

## 运行 A0 受控验收

在项目根目录和已安装 `requirements-test.txt` 的环境中运行，输出目录必须不存在：

```powershell
python benchmarks/run_chinese_acceptance.py `
  --data-dir data/processed/movies_5000_20261029 `
  --model-path models/pipeline_5000_20261029/model.pkl `
  --output-dir output/chinese_controlled_acceptance_01 `
  --prior-diagnostic verification/2026-10-30/chinese_qa/summary.json
```

该操作不训练模型，A0 部分不联网。可用 `--movies-per-split` 明确改变样本规模；更改后应作为另一组结果记录。已有目录即使为空也会被拒绝，防止覆盖证据。先将 `questions.jsonl` 写入并记录 SHA-256，再从实际图谱构建独立 `gold.jsonl`；预测器仅接收冻结文件中的原始问题字符串。实际调用 `PipelineQA.predict(原始中文问题)`，同时覆盖中文适配与 A0 集成。

结果包含：

- `fixture_freeze.json`：模板、选片规则、选中电影和题目文件 SHA-256。
- `predictions_a0.jsonl`：实际 A0 输出和每题 ID。
- `scored_a0.jsonl`：实际输出与标准答案的逐题比较，包括实体集合精确匹配、电影链接、输入意图、分类器关系、拒答和中文输出标记。
- `summary.json`：整体、分划分、分变体指标，数据/模型/实现 SHA-256，输入文件前后不变检查，以及中文标签覆盖和名称回退说明。

指标按 0—1 比例记录。拒答正确要求 `refused=true` 且答案 ID 为空，空答案本身不计为正确拒答。中文输出覆盖只说明输出含中文字符，不等同于答案正确，也不代表所有实体名称都有中文翻译。`PASS` 表示本组受控题目的所有 A0 检查通过；有失败时保留实际结果并返回非零退出码。选中片名若仍有歧义，会如实记入失败。已保存的 v2 CPU 结果为 240/240 正例实体集合匹配、20/20 负例正确拒答、260/260 输出含中文；这些数值仅适用于上述受控范围。结果见 `verification/2026-10-30/chinese_qa_v2/summary.json`。

加入中文展示名目录后的最终复核见 [最终受控验收](../verification/2026-10-31/chinese_qa_final/summary.json)。题目文件与原 v2 逐字节 SHA-256 一致，A0 仍为 240/240 正例匹配、20/20 负例正确拒答；450 次答案实体出现中，375 次具有中文展示名，其余保留原名。另有 [8917 道原英文测试题回归](../verification/2026-10-30/chinese_english_regression/summary.json)，相对冻结 A0 的电影 ID、关系 ID、答案实体集合和答案原文均无变化。公开证据中的解释器路径仅显示 `python`，原始路径版本已私下保留，路径归一化清单记录原始与公开文件 SHA-256，指标未改动。

## 可选真实神经 HTTP 样本

先在含完整 B0 资产和同一 5000 部电影数据的独立运行包中启动双系统服务，再增加：

```powershell
python benchmarks/run_chinese_acceptance.py `
  --data-dir data/processed `
  --model-path models/pipeline/model.pkl `
  --output-dir output/chinese_controlled_with_http_01 `
  --http-url http://127.0.0.1:7860 `
  --http-sample-size 16 `
  --http-model-dir runs/B0
```

此处的路径是运行包路径，不能与源码中的版本化数据目录混用。脚本真实请求 `GET /api/status` 和 `POST /api/answer` 的 `best` 系统，默认优先覆盖四种关系 × valid/test 的八个正例及八个负例，保存原始响应、正例实体精确匹配和负例拒答。服务不可用或模型返回错误时记录失败；完成但答错时如实保留指标，不以 A0 的成功替代神经输出。该小样本仅是实际服务冒烟检查，不构成神经中文准确率研究。

`--http-model-dir` 对操作者指定的文件记录 SHA-256；HTTP 接口本身不能证明服务实际加载了同一检查点，因此结果中明确保留这一身份限制。不提供该参数时仅记录服务报告的运行 ID。

最终真实 B0 + 名称恢复服务的 16 题结果保存在 [HTTP 原始样本](../verification/2026-10-31/chinese_qa_final/neural_http_sample.json)：8 个正例实体集合全部匹配，实体宏平均 F1 为 1.0，8 个负例正确拒答，16 个输出均含中文。原始英文生成、实际答案 ID 和名称恢复信息均保留。这仍然只是固定模板的八个可回答输入，不能称为中文神经模型的一般准确率。

HTTP 服务必须在状态中声明支持中文，并在实际响应中提供 `answer_ids` 与 `language=zh`；旧接口缺失字段时应判为不可评分，不能把缺失 ID 当作模型预测空集合。首次旧服务部署诊断保存在 `verification/2026-10-31/chinese_qa/evaluation_validity.json`，已标记 HTTP 指标无效，不纳入最终神经样本结果。
