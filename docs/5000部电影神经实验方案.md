# 5000部电影神经训练与对照方案

本轮使用已分发的冻结5000部电影库，快照SHA-256为`486faa982e84fd5781f62872fd02db11100fad82a013b37f454bbe4da520d867`。本文件说明执行方案；数值结论以完成后的逐题预测和实验报告为准。

## 数据和比较范围

7864实体、35485三元组、58994问答。按电影划分3500/750/750，问答划分41220/8857/8917，种子42。所有方法访问相同冻结图谱，测试电影事实可查询；这是已知知识库中的新问题，不作为未知边或开放域实验。

配套A0权重和阈值0.30保持冻结，不重新拟合。TransE在本版图上重新训练100轮，100维实体/关系向量，学习率0.001、batch256、每正例5个基础负样本并过滤已有边。旧200部电影向量和检查点不用于本轮初始化。

| 配置 | 学习率 | 结构前缀 | 训练轮数 |
|---|---:|---|---:|
| B0 | 1e-4 | 冻结TransE经可训练投影与归一化 | 5 |
| B1 | 3e-5 | 同B0 | 5 |
| B2 | 3e-4 | 同B0 | 5 |
| B3 | 1e-3 | 同B0 | 5 |
| C0 | 1e-4 | 无，仅事实文本 | 5 |

五组均从同一FLAN-T5-small预训练版本`0fc9ddf78a1e988dac52e2dac162b0ede4fd74ab`开始。训练batch8、累积2，名义有效batch16，最后更新可能较小；独立seed42生成器保证各组训练问题顺序一致。输入512、目标及生成上限96、最多24条事实。训练BF16，验证与测试生成float32、greedy、单束、无采样，评价batch64，CPU线程4。显存与吞吐校准只使用训练问题或合成张量维度，不据测试分数选配置。

## 模型选择与评分

每轮完整计算8857道验证题的损失和实体F1，仅严格提升时保存检查点，因此轮次同分保留较早轮。在B0–B3中按验证F1选模型，同分选较小编号；C0仅作结构消融对照。各组最后恢复自己的验证最优检查点，再完整生成8917道测试题。

神经答案先根据其自身句式识别答案部分，再提取实体。只使用实际链接电影的检索事实解决同名多QID歧义；不读取标准关系或答案。短ASCII别名按原大小写识别，避免把介词`in/by`和连接词`and`误计为实体；匹配不跨列表逗号/分号，除非原名称含该标点。唯一且不属于当前事实的额外实体仍计入预测，不能通过过滤幻觉提高F1。旧解码器及历史200部成绩保留。

新解码器在全部41220道训练题、78693个参考句上经过独立检查，参考答案实体解析零错误。此检查用于确认解析实现正确，不等于模型生成成绩。BLEU和ROUGE-L仍在完整生成句上计算。

## 执行与复核

完整环境及本地预训练缓存就绪后，在仓库根目录执行：

```powershell
python -m kgqa.expanded_suite --work-dir output/expanded-neural --model-name <本地预训练模型目录>
```

runner建立隔离`project`，复制冻结数据和A0，记录源码与输入哈希，依次运行100轮TransE及五组神经训练。权重留在工作目录。`--resume`仅复用状态完整且哈希一致的阶段；失败或半成品不会被覆盖。最终输出`selected_model.json`及`suite_summary.json`，检查点、日志、逐题预测、损失与指标分别归档。

基础模板测试与改写、错拼、别名和拒答分别计分，扰动只与同源原题配对。主比较使用原始神经生成。A0单题CPU管道延迟与神经batch生成按题摊销的计时范围不同，不直接相除宣称加速倍数。

名称恢复作为独立附加方法，将既有200部电影实验中的`NameRecovery`原样迁移到本版，不重新训练或调整阈值。[附加评价入口](../benchmarks/run_frozen_recovery.py)使用当前`AnswerEntityIndex`，仅根据实际链接电影的最多24条保留事实尾实体恢复唯一可识别的分词器往返损坏名称，并以相同检索上下文消解同名实体；恢复阶段不读取标准关系或答案，标准数据仅用于随后评分。原始基线保留已保存的`answer_ids`，重新提取若有差异则单独记录，不替换主指标。

先在完整验证集评价并冻结适配程序、数据、分词器和方法协议，套件全部结束后仅对原始验证F1选出的B模型进行匹配协议的验证复核，再以该验证报告对测试及鲁棒性各评价一次。恢复结果不参与B模型选择，不覆盖原始预测、主成绩或检查点。[B0验证附加评价记录](../verification/2026-10-30/name_recovery/B0_valid/report.json)已覆盖8857题：修复24题、回退0题，恢复后实体集合准确率与F1均为100%，原始ID重新提取差异0题。这仅是B0的验证结果，不是最终模型或最终测试成绩。

周新永负责A0、实体链接、评测与鲁棒性；夏俊杰负责版本核验、TransE、神经学习率和消融。两人报告共享同源结果，按各自负责模块说明贡献。人工评分和真实截图按本人取得的材料补入，不用自动指标代填。

## 训练后统一实体解析修订

训练及原始选模使用冻结解析器v1。测试后的误差检查发现，完整双导演姓名可被最长短语匹配识别为一个组合条目。v2在实际保留事实中要求完整串由至少两个实体和显式连接词覆盖；组合条目本身属于候选时保留原有匹配。所有系统、完整验证与测试、选中模型鲁棒性及固定名称恢复输出均按同一v2接口复评，权重、生成文本、学习率和检查点不变，B0选模结果也不变。

[统一复评与旧新对照](../verification/2026-10-30/decoder_revision_v2/summary.json)保留测试后修订标记、逐题ID变化和356份原文件的复评期间字节一致性记录。规范参考句共112625次解析，v2无错配；344项测试通过。原评分归档保留，名称恢复仍作为附加方法单列。发布时仅将A0阈值摘要的三个本机路径字段改为相对路径，数值及输入、模型、源码哈希不变，见[发布路径归一化记录](../verification/2026-10-30/publication_path_normalization.json)。
