## 启动与使用

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m kgqa.web --port 7863 --data-dir data/processed/movies_5000_20261029 --model-path models/pipeline_5000_20261029/model.pkl
```

打开`http://127.0.0.1:7863/`，勾选“扩展事实问答”。此入口使用规则计划和只读工具，按问题语言组织证据答案，和原来的标准/四关系自然问法分开。

可以问：

```text
《盗梦空间》的导演和演员是谁？
Who wrote Inception?
When was Inception released?
Who wrote Inceptoin?
盗梦空间和星际穿越有哪些共同演员？
盗梦空间的导演还拍过哪些电影？
Compare the directors of Inception and Interstellar
```

错拼、不完整标题和同名电影返回候选，点击确认后查询。来源可点击，地区等限定条件原样展示；长列表通过“下一页”读取，不把首30条伪装成完整列表。

目前解析仍是有限中英规则，不代表任意自然语言都可理解。预算、主演身份、配音版本、指定地区/日期/否定过滤、剧情、推荐等未完成任务会说明限制；导演/演员等事实可一次问多个。日期比较目前列出来源记录，不自动推断全球首映；数值排序只有唯一且明确同币种/范围/其他限定条件一致时才执行。

CLI也可使用：

```powershell
.\.venv\Scripts\python.exe -m kgqa.explorer --question "Who wrote Inception?"
.\.venv\Scripts\python.exe -m kgqa.explorer --question "Who wrote Inceptoin?" --movie-id Q25188
```

API：`POST /api/explore`，字段为`question`、可选确认用`movie_ids`、`offset`、`limit`。返回`plan/status/answer/evidence/items/missing/total/next_offset`。原`POST /api/answer`默认行为不变。

## 重新采集/补名

```powershell
# 只生成审计选择，不改原数据
.\.venv\Scripts\python.exe -m kgqa.v2_data select --output output/catalog_v2/selection.json

# 复用声明和名称缓存，向官方端点补剩余名称；输出路径必须是新目录
.\.venv\Scripts\python.exe -m kgqa.v2_data build --count 5000 --output-dir data/processed/movies_v2_named_next --proxy http://127.0.0.1:7890

# 若端点仍限流，只冻结已有名称和完整声明，未解析名称统计并显示QID
.\.venv\Scripts\python.exe -m kgqa.v2_data build --count 5000 --output-dir data/processed/movies_v2_cached_next --offline-labels
```

使用新目录时给网页/CLI传`--catalog-dir`。采集与问答分开，问答入口不实时请求Wikidata。没有改动同伴训练数据或检查点，也没有让当前训练热加载新增问题。
