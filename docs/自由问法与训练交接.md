# 自由问法与 5000 部电影训练交接

## 正在训练的模型如何知道新问法

**它不会自动知道。** 现有 `neural.train()` 在训练开始时一次性读取 QA，再创建 DataLoader。之后修改磁盘文件不会更新这次训练里的样本，更不会自动更新模型权重。本次没有改动原始 5000 部数据和模型。

当前训练继续作为“原问句版本的 5000 部电影基线”。新的自由问法有两种明确用法：

1. **现在使用适配层。** 自然问句 → 电影与关系 → 标准英文问题 → 现有系统。旧生成模型看到的是其熟悉的标准问题；外部解析层负责理解问法。这不能写成旧模型已经学习了新问句。
2. **下一轮真正学习新问句。** 从独立的自然问法数据目录启动新训练，或者以配套检查点为起点微调；训练记录会保存所读取 QA 的哈希及各划分题数。

## 当前可用功能

第一版支持单电影、单关系的导演、类型、制作国家和原始语言，采用显式规则与词典。英文自然表达、已收录中文片名/别名和部分中文关系问法会转为英文标准问题，答案仍为英文。支持已收录英文片名的既有模糊匹配，不提供通用中文拼写纠错或简繁转换。

例如：

| 原问题 | 给现有模型的问题 |
|---|---|
| `Could you tell me who helmed The Avengers?` | `Who directed The Avengers?` |
| `《盗梦空间》是谁执导的？` | `Who directed Inception?` |
| `The Matrix的原始语言是什么？` | `What is the original language of The Matrix?` |

同名电影、多个电影或多个关系会提示澄清；预算、票房、演员、拍摄地等未支持事实拒答。规则不保证理解所有自由表达；这是受限自然问法入口，不是开放域聊天。

网页在服务声明支持后显示“自然问法”选择，默认勾选；可取消勾选回到标准模式。API 的 `mode` 缺省仍为 `standard`，实验 CLI 不自动启用适配。页面和结果 JSON 保留原问句、标准问题、解析方式、澄清信息和事实证据。标准问题的分类置信度不代表原自由问句的理解置信度。

当前 5000 部片库先使用已有 A0；其神经模型尚未在本次集成。原有配套神经系统可通过同一模式接收标准化问题，新 5000 部神经检查点须在同伴交付后另行核对数据、嵌入和模型配对再接入。

## 立即试用

原 `.venv` 或 `requirements-test.txt` 环境即可运行 A0，无需 GPU：

```powershell
.\.venv\Scripts\python.exe -m kgqa.freeform --question "Could you tell me who helmed The Avengers?"
.\.venv\Scripts\python.exe -m kgqa.web --port 7862
```

打开 http://127.0.0.1:7862/ 。既有 7860/7861 服务不自动停止；新模式需要启动加载了本次代码的服务。

## 独立训练数据

原始版本仍是 `data/processed/movies_5000_20261029/` 的 58994 道题。已另存：

`data/processed/movies_5000_freeform_en_v1/`

| 划分 | 电影数 | 问答数 |
|---|---:|---:|
| train | 3500 | 73202 |
| valid | 750 | 6868 |
| test | 750 | 6904 |
| 合计 | 5000 | 86974 |

实体、三元组及电影划分按字节复制，图谱没有改变。仅训练集保留原训练问句并增加改写；验证和测试采用不同的人工编写句式族，答案仍来自同一冻结图谱。`manifest.json` 记录来源哈希、完整句式、来源题号及计数，QA 记录额外带 `question_source` 和 `source_question_id`。

这是**受控合成改写数据**；不同句式族的测试只能作为回归检查，不能代替由其他人独立撰写的自然问题测试。不可根据测试题反复调整训练问句并继续声称测试独立；开发时使用验证集。正式比较时，让所有待比较系统回答同一套新测试题，不能直接把旧模板测试分数与新改写测试分数相减。

其他机器可从同一份已发布 5000 部数据重新导出：

```powershell
.\.venv\Scripts\python.exe -m kgqa.freeform_data --output-dir data/processed/movies_5000_freeform_en_v1
```

命令拒绝覆盖已完成目录。需要重做时使用新版本目录；不要把新问句写回同伴当前训练的 `qa.jsonl`。

## 训练完成后微调

以下路径 `runs/B0_5000/checkpoint` 和 `models/transe_5000` 是示例，请替换为同伴实际交付的 **5000 部电影配套** 检查点和嵌入，不能使用原 1000 部的向量。本次未执行这条 GPU 训练命令：

```powershell
.\.venv\Scripts\python.exe -m kgqa.neural `
  --run-id B0_5000_freeform_v1 `
  --data-dir data/processed/movies_5000_freeform_en_v1 `
  --embedding-dir models/transe_5000 `
  --initial-checkpoint runs/B0_5000/checkpoint `
  --learning-rate 3e-5 --epochs 3 --batch-size 4 --gradient-accumulation 4
```

学习率和轮数是下一轮试验的起始建议，不是已验证的最佳参数。微调重新创建优化器与调度器，不恢复旧优化器进度；验证集实体 F1 选择新检查点，测试集不参与选模。新运行名已存在且非空时拒绝覆盖。若不做微调，省略 `--initial-checkpoint` 可从默认预训练模型开始；无结构前缀的文本对照需使用 `--no-embeddings` 并单独记录实验设置。

数据图谱不变时可以复用匹配的 5000 部嵌入；加载时检查映射覆盖，缺少新实体或关系会停止。训练配置记录数据与嵌入路径、QA/实体/划分哈希、初始检查点、批大小及题数。推理默认读取该运行配置中的路径，不偷偷返回原默认数据。

新训练完成并写出测试预测后，可用 `python -m kgqa.metrics B0_5000_freeform_v1` 计算测试指标；评测同样读取运行配置中的数据目录，不会将新预测与旧模板题错配。改写数据尚未生成配套扰动集，不能直接复用原版 `robustness.jsonl`。

交接时至少提供：代码版本、数据 manifest、配套嵌入目录、初始检查点来源、启动命令，以及实际 `runs/<新运行>/config.json`。同伴取得这套代码与新数据后再启动新运行，才会学习新增问句；本次没有自动给同伴发消息。
