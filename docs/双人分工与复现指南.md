## 本次已经落实的优化

1. 实体链接使用问题中的标题片段和实际序列相似度，增加候选差距检查；多电影或共享别名不确定时拒答。
2. A0 的训练、验证和推理统一遮蔽标题、别名和可接受的错拼片段；验证不使用金标准电影名替代实际链接结果。
3. A0 演示延迟加载神经组件，不再强制依赖神经检查点及 `selected_model.json`。
4. 指标拒绝重复、未知、缺失题号和空输入；保留整体指标，同时分别报告可回答题和拒答题。文本实体名称索引按本次推理显式复用。
5. 人工评价按电影轮转并优先较少抽样的关系，固定随机种子并保存清单；这是一种诊断抽样，不声称统计代表性。评分为空，答案密钥单独保存。
6. 停止生成模仿终端的图片，只导出真实记录摘要。

## 无模型验证

在仓库根目录的独立 Python 环境中执行：

```powershell
python -m pip install -r requirements-test.txt
python -m pytest -q
python benchmarks/run_linker_benchmark.py --output output/verification
```

本轮使用 Anaconda 继承环境加独立安装的指标依赖。实际版本写入 `verification/2026-10-18/linker_benchmark.json`，与完整 GPU 训练依赖环境不同。44 条用例覆盖 10 个手工实体，含 32 个有明确目标的查询和 12 个应拒答查询。默认阈值 0.88、候选差距 0.06；参数扫描 0.72/0.80/0.88/0.96，各运行三遍。不要根据这组回归题反向选择正式实验参数，应使用正式验证集。

2026-10-19 已追加长片名错拼与短片名冲突的回归修复，并检查完整片段遮蔽。当前方案仍不是通用实体消歧器；数字续集、普通短词与复杂语义歧义仍需独立评测，回归集满分不代表全部长尾问题已经解决。


B2 只是在原实验中的验证最优；新训练应使用新验证选出的实际编号。将 `output/human_evaluation.csv` 分别复制给两人；不提前打开 key 和 manifest 中的系统映射。准确性 0/1/2 表示错误/部分正确/全部正确，完整性 0/1/2 表示遗漏全部/遗漏部分/无遗漏，流畅度 1–5 从难以理解到自然流畅，unsupported_claim 0/1 表示无/有无依据事实。先独立填分，再对分歧逐题核查并保留原始评分。报告每系统均值、样本数、无依据比例和分歧处理方法。禁止用 BLEU/ROUGE 或 AI 代填主观评分。
