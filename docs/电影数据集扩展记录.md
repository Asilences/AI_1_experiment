## 数据如何取得与清洗

1. 从 Wikidata Query Service 获取具有电影类型、导演和至少 15 个 sitelink 的候选，按 sitelink 数降序及电影 URI 排序，最多 8500 个。它优先覆盖常见电影，存在流行度、语言与元数据完整性的筛选偏差，不是随机抽样。
2. 候选与原库重叠的 QID 跳过。从 8092 个可新增候选中实际检查 4140 个，接受 4000 个、拒绝 140 个。
3. SPARQL 服务在候选取得后返回故障期间的限流提示，实际事实采集改用 Wikidata 官方实体 API。保留 167 份缓存响应、请求参数、提取时间和实体修订号；失败不写成功缓存，支持断点续跑。
4. 新电影复查直接电影类型，读取导演 P57、类型 P136、国家 P495、语言 P364。按 preferred/normal rank 处理，忽略 deprecated、未知值和非实体值。
5. 至少三类关系有完整英文答案标签，且每类可用于问答的答案为 1—3 个，才纳入问答数据。图中可以保留更多有名称的真实事实；不因为答案数量多就把事实改成单答案。
6. 原快照未覆盖名称的悬空事实只在新版本中清理。校验显示原 `triples.tsv` 的所有有效三元组仍包含在扩展图内，原文件与模型没有覆盖。
7. 同名电影保留官方标签，另外提供片名+年份或 QID 的消歧别名；单字母片名 M、Q、R 使用带年份/ID 的问题入口。对 5000 部电影的四种标准问法共 20000 条进行了链接检查，没有错误。

年份取当前 best-rank P577 日期的最小年份，只作消歧辅助，没有独立核实为首次首映年份。中文标签/别名按 Wikidata 原值保存和搜索，部分名称仅有繁体或其他地区写法，尚未提供通用简繁转换。中文片名可用于搜索，关系问答仍使用英文。

原 1000 部电影保留旧快照中有效事实与标签的历史来源；新增记录来自本轮请求，因此这是明确记录来源的混合版本，不能声称全部事实都更新到了同一天。

## 划分、模型与评测

保留原 700/150/150 部电影各自所属集合，新增 4000 部用种子 42 打乱后补足 3500/750/750。同一电影的问句和改写都继承电影划分，没有电影 QID 跨集合。

在独立目录训练了配套 A0 模型，并仅在验证集选择关系阈值。8917 道测试题完整覆盖，实体集合准确率与 Macro-F1 均为 100%，BLEU 和 ROUGE-L 也为 100%。训练和测试共享固定问题模板，知识库包含待查询电影的事实，因此这些分数仅说明受控模板流程通过，不能解释为自由问法或开放域泛化能力。

原 TransE/B2 的实体映射与权重对应 1000 部电影，**本轮没有将旧向量套用到新实体，也没有声称已完成 5000 部电影上的神经训练或新的 A/B 对比**。扩展库启用 A0；原库的双系统入口完整保留。

## 使用与复现

其他人克隆包含数据发布的分支后，安装 `requirements-test.txt`，执行 `python -m kgqa.dataset activate --smoke` 即可验证全部文件、配套模型和示例问答，并激活本机 UI。直接使用不需要重采集、重训或恢复原 1000 部片库。

默认界面已激活扩展库：

```powershell
.\scripts\run_ui.cmd
```

使用原 1000 部电影和 B2：

```powershell
.\scripts\run_ui.cmd -Legacy -Port 7861
```

扩展流程的完整复现/续跑命令：

```powershell
.\.venv\Scripts\python.exe -m kgqa.expand --target 5000 --candidate-cache data/raw/expansion_5000_20261029/candidates_sitelinks15.json --work-dir data/raw/expansion_5000_20261029 --proxy http://127.0.0.1:7890 --output-dir data/processed/movies_5000_20261029 --model-dir models/pipeline_5000_20261029 --base-splits data/processed/splits.json --activate
```

无代理时省略 `--proxy`。第一次需要原 1000 部电影快照及其划分；缺少候选缓存时才在线查询候选。已有快照、数据与模型会核对输入和文件哈希，不覆盖原实验；更换数据来源应使用新的版本目录。`.work/ui-dataset.json` 只在准备、训练和评测成功后生成，重启界面后生效。
