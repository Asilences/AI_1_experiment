# 人工评价操作说明

任务书第4项要求真人判断准确性、完整性和流畅度。样本来自冻结5000电影主实验中相同100道测试题的A0与验证选择的B0，共200份答案，抽样种子、预测哈希和匿名映射见`reports/人工评价/5000部电影_20261030/`。这项评价针对主实验，不能宣称P0或新微调模型已获真人验证。

## 实际评分

从项目根目录运行，保持服务开启：

```powershell
.\.venv\Scripts\python.exe -m kgqa.human_review_web --port 7865
```

打开 http://127.0.0.1:7865/ ，输入本人代号，如`xia`或`zhou`。不要提前查看`human_evaluation_key.csv`中的系统映射。先看问题和冻结知识库参考答案，再对两份匿名答案分别核查。页面先给出一条基于参考答案相似度的 AI 辅助建议：点击 **√** 表示你确认这四项建议，点击 **×** 展开准确性、完整性、流畅度和无依据断言四项评分后自行修改。页面也提供电影Wikidata来源链接；当前在线页面可能晚于冻结快照，不能将在线变化直接算成冻结系统错误。未经你确认的建议不会写入评分文件。

| 项目 | 分值及标准 |
|---|---|
| 准确性 | 2：事实与问题完全相符；1：部分正确但含事实错误或关系不准；0：错误、无关或应答时拒答。不可答题以正确拒答为准确。 |
| 完整性 | 2：覆盖所需全部答案且适当说明缺失；1：漏掉部分；0：未覆盖所需信息。 |
| 流畅度 | 1—5：从难以理解到语法自然、表述清楚。与事实正确性分开评分。 |
| 无依据断言 | 1：出现证据不支持的事实断言；0：未发现。 |

四项均填完后保存。支持前后切换、续填、修订，服务端保留修改事件。目录为`H:\AI1experiment\output\human_review\`，每名评价者有JSON、事件JSONL和CSV。不要使用同一个代号覆盖另一人的记录。

至少一名真人完成全部200份答案后才能汇总；教师未强制两名。√确认属于“AI辅助、人工逐题确认”，不能写成未经人工核查的自动评分。多人时独立评分并保留原始分歧，解码后另报一致性。不要只点击√而不阅读答案和参考；也不要用LLM或自动指标代替确认。

## 汇总与归档

以下以实际完成的`xia`表为例，文件不完整会拒绝汇总，空白不当零：

```powershell
.\.venv\Scripts\python.exe -m kgqa.human_eval --score-file output/human_review/reviewer-xia.csv --key-file reports/人工评价/5000部电影_20261030/human_evaluation_key.csv --summary-output output/human_review/summary.json
```

两人实际均完整时，追加`--score-file output/human_review/reviewer-zhou.csv`。单人只报真实人数及每系统100份答案的统计，不编造一致性。

最终归档完整CSV、事件日志、summary和代号/日期说明至新版本目录，再按真实结果更新报告。`output/`默认不进Git；当前提交只含评分入口与固定空白样本，不表示人工实验已完成。
