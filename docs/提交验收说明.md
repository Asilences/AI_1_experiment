## 安装与双系统现场演示

完整运行包解压后，进入包含`kgqa`、`requirements.txt`的根目录。使用Python 3.12，在Windows PowerShell中执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-runtime-cpu.txt
.\.venv\Scripts\python.exe -m kgqa.web --legacy --open
```

首次安装依赖需要网络；运行包中的本地数据与完整检查点用于后续推理，无需重新采集或训练。本页默认使用`requirements-runtime-cpu.txt`部署CPU推理，已在独立环境完成四项离线测试。GPU部署另建环境安装`requirements.txt`（CUDA 12.4），启动命令相同；完整训练使用完整依赖。神经模型首次回答时加载，首次响应可能较慢。

浏览器打开`http://127.0.0.1:7860/`，保留启动终端，按`Ctrl+C`停止。`--legacy`绕过本机已激活的A0专用配置，读取运行包默认的`data/processed`、`models/pipeline`和`output/selected_model.json`。此处的“legacy”是路径选择参数，不表示使用旧200部电影数据。不要为双系统演示添加`--data-dir`或`--model-path`，这两个自定义参数会进入仅A0模式。上述双系统命令面向完整运行包；源码克隆中的发布数据位于独立版本目录，不能仅凭`--legacy`认定默认路径已恢复齐全。

在另一个PowerShell窗口检查服务，随后从当前片库示例中选题请求双系统：

```powershell
$state = Invoke-RestMethod http://127.0.0.1:7860/api/status
$state | Select-Object movie_count, dataset_name, custom_data, a0, neural | ConvertTo-Json -Depth 5
$question = $state.examples[0].question
$body = @{ question = $question; system = 'both' } | ConvertTo-Json
Invoke-RestMethod -Uri http://127.0.0.1:7860/api/answer -Method Post -ContentType 'application/json' -Body $body | ConvertTo-Json -Depth 8
```

验收时实际核对`movie_count`为5000、`custom_data`为`false`，A0和神经模型均可用；神经`run_id`应与包内验证选模记录一致。`/api/answer`应返回`a0`、`best`两项实际结果，逐项检查`ok`、答案、实体与事实证据。另选导演、类型、国家、语言、多答案、别名及应拒答问题，记录实际答案和错误、缺失情况；服务启动与回答质量分别验收。

## 从源码复现实验与查看证据

只核对源码随附的5000部电影数据和A0资产，可在安装依赖后运行：

```powershell
.\.venv\Scripts\python.exe -m kgqa.dataset verify --smoke
```

完整重新训练使用[5000部电影神经实验方案](5000部电影神经实验方案.md)。准备完整环境和本地FLAN-T5-small预训练缓存，修订为`0fc9ddf78a1e988dac52e2dac162b0ede4fd74ab`，然后在源码仓库根目录执行：

```powershell
$pretrained = '<本地完整预训练缓存目录>'
.\.venv\Scripts\python.exe -m kgqa.expanded_suite --work-dir output/expanded-neural --model-name $pretrained --batch-size 8 --eval-batch-size 64 --input-max-length 512
```

将占位内容替换为实际目录。runner新建隔离`project`并复制冻结资产，训练100轮TransE及五组各5轮神经配置；不要使用正在运行或已有半成品的工作目录。`--resume`仅复用状态完整且哈希一致的阶段，不能用来覆盖失败结果。每轮完整验证8857题，仅严格提升时保存检查点；B0—B3按验证实体F1选择，同分取较小编号，C0只作消融。各组恢复自己的验证最优检查点后完整测试8917题，不按测试成绩反选模型。各配置仅seed42一次训练，结论限于本轮条件。

已归档的[本轮证据目录](../verification/2026-10-30/)与[本轮结果摘要](../verification/2026-10-30/neural_summary.json)提供实际配置、输入哈希、曲线与逐题预测。B0/B1/B2原始验证F1同为99.778706%，按较小B编号选B0，最佳轮为第3轮；B3为99.765158%，C0不参与选模。完整8917题原始测试的实体F1为A0 100.00000%、B0/B1/C0 99.52899%、B2 99.46170%、B3 99.51553%；六系统准确率、BLEU与ROUGE-L见[项目结果表](../README.md#实际结果评分与名称恢复)。B0与C0在相同学习率1e-4下的测试实体F1相同，本轮未观察到该指标的结构前缀收益。
