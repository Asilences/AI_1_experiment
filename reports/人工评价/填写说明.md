# 人工评价填写说明（2026-10-29）

同一份抽样表包含 200 条答案。两位评价者各填自己的原始评分表；评分前不要打开对照密钥和包含系统映射的 manifest。
准确性 0/1/2：错误或无证据 / 部分正确 / 全部正确。
完整性 0/1/2：未覆盖 / 部分覆盖 / 完整覆盖标准答案。
流畅度 1–5：难以理解到自然流畅。无依据断言 0/1：未发现 / 发现，在 notes 写明具体问题。
未实际评价的行保持空白，不得写成 0 分。提交统计前，两份表的所有答案行均须填齐四项评分。不要改 question_id、answer_position、问题、参考答案或模型答案。
两人先独立填写，保留原表，再讨论分歧；讨论记录另存，不能覆盖独立原始评分。
对照密钥仅由组织者保管，完成独立评分后再按系统统计。自动 BLEU/ROUGE/实体 F1 不能代填主观评分。

在仓库根目录运行当前统计入口：

```powershell
python -m kgqa.human_eval --score-file reports/人工评价/周新永_评分表.csv --score-file reports/人工评价/夏俊杰_评分表.csv --key-file reports/人工评价/对照密钥.csv --summary-output verification/2026-10-29/human_evaluation_statistics.json
```

只有两表全部答案行的四项评分完整且合法，才生成 verification/2026-10-29/human_evaluation_statistics.json。空白或不完整评分会被拒绝，不会作为零分参与计算。
统计使用公开可下载代码中的 kgqa.human_eval 入口；两人的原始 CSV 均不修改。
