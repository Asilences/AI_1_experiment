# 5000部电影人工评价

本表来自同一测试划分中的100道问题，覆盖100部电影，四类关系各25题。每题包含A0和验证集选中B0的两条匿名答案，共200行。这里使用原始生成文本；名称恢复与实体解析修订另由自动指标评价。

周新永填写`周新永_评分表.csv`，夏俊杰填写`夏俊杰_评分表.csv`。两人先独立评分，再查看`human_evaluation_key.csv`中的系统映射和讨论分歧。`human_evaluation_manifest.json`记录实际抽样与排列。

只填写以下四列及`notes`，保留题号、答案位置、原题、参考答案和模型答案。

| 列 | 分值 | 含义 |
|---|---|---|
| `accuracy_0_2` | 0–2 | 答案事实是否准确 |
| `completeness_0_2` | 0–2 | 是否完整回答问题 |
| `fluency_1_5` | 1–5 | 句子是否通顺 |
| `unsupported_claim_0_1` | 0或1 | 是否包含参考事实以外的断言 |

空白表示尚未评价，0是有效评分。当前两份表均为空表。填写完成后在仓库根目录运行：

```powershell
python -m kgqa.human_eval `
  --score-file reports/人工评价/5000部电影_20261030/周新永_评分表.csv `
  --score-file reports/人工评价/5000部电影_20261030/夏俊杰_评分表.csv `
  --key-file reports/人工评价/5000部电影_20261030/human_evaluation_key.csv `
  --summary-output output/human_evaluation_5000_statistics.json
```

保留两份独立原始评分；讨论后的版本另存。统计程序检查题号对应、分值范围与完整性，输出各系统四项均值及评价者一致情况。
