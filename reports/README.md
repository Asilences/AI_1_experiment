## 结果口径

- V1主实验：5000电影、35485三元组、58994问答，完整测试8917题。TransE100轮，B0—B3和C0各5轮，原始验证选中B0。[主汇总](../verification/2026-10-30/neural_summary.json)、[评分修订v2](../verification/2026-10-30/decoder_revision_v2/summary.json)及原始逐题输出分别保留。
- A0主测试F1为100%，原始B0为99.52899%；同模板、完整已知图谱的成绩不代表任意自然语言理解。[补充阈值记录](补充阈值运行记录/README.md)保留高阈值造成误拒答的诊断。
- 自由问法v2混合测试6904题，F1为69.4081%。其中738题模板已见、F1为100%；其余6166题F1为65.7466%。由保存预测实际重算，[分组记录](../verification/2026-10-31/pr12_audit_fixes/freeform/rescore/summary.json)可复核；不再称整套为“全部未见问法”。
- P0原20题开发结果不变；本轮最终答案改为受控证据句。对保存输出的[离线控制器重放](../verification/2026-10-31/pr12_audit_fixes/p0_guard_replay/summary.json)回退13/20，不是新模型实验或独立测试。
