## 已完成的5000部电影实验

本轮数据为5000部电影、7864个实体、35485条三元组、58994道问答。电影划分3500/750/750，问答划分41220/8857/8917，种子42。训练batch8、梯度累积2、名义有效batch16，评价batch64，输入512、目标与生成上限96、最多24条事实；训练BF16、生成float32贪心解码。
