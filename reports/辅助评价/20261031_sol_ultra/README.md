# 双独立模型辅助评价

2026年10月31日，对同一100题、200条匿名原始答案开展两次独立模型评价。两次均使用gpt-6.1-sol，推理强度ultra；每次200条，每条四项分值及中文依据，共400条记录。该记录为AI辅助评价，不代表两位作者亲自进行真人评分，课程人工评价状态未因此完成。

| 文件 | 内容 |
|---|---|
| [双独立自动辅助评价.xlsx](双独立自动辅助评价.xlsx) | 四行分模型上下文、分系统均值；一致率；400条原判、来源、依据和计算公式。 |
| [自动辅助评分_评审01.csv](自动辅助评分_评审01.csv)、[评审02](自动辅助评分_评审02.csv) | 各200条；前五列保留原题、参考、位置和答案，另有模型、推理强度及评价类型。 |
| [原始JSONL 01](自动评审01_原始.jsonl)、[02](自动评审02_原始.jsonl) | 两次独立判断的原始分值与理由，不裁决分歧。 |
| [元信息01](自动评审01_元信息.json)、[02](自动评审02_元信息.json) | 启动模型/推理参数、所读输入、盲评范围与覆盖核验。 |
| [辅助评价汇总](辅助评价汇总.json)、[分歧记录](分歧记录.json) | 按固定系统映射完成评分后汇总，保留唯一分歧。 |
| [评分细则](inputs/rubric.txt)、[输入题集](inputs/cases.jsonl)、[来源信息](inputs/source_identity.json) | 固定的四项锚点、100题及匿名答案、来源提交与样本范围。 |

被评数据来自固定提交[077a18ce](https://github.com/Asilences/AI_1_experiment/tree/077a18ce165f10cd998dcd1c82f403796aef3559)中的[匿名原表](../../人工评价/5000部电影_20261030/human_evaluation.csv)，抽样seed42，100部电影，导演、类型、国家、语言各25题。评分时不展示系统身份、对方结果或既有成绩，不联网补全事实；完成后按既有密钥解码。本次模型调用参数是评审配置记录，不额外声称存在独立的后端参数鉴定。

上下文01对A0/B0准确性与完整性均值分别为2.00/1.99；上下文02两系统均为2.00。两次流畅度均为A0 4.46、B0 4.45，均未标记参考不支持的新增断言。唯一分歧是B0将Miloš Forman写为Milo Forman的扣分边界；四项同时一致为199/200（99.5%），不解释成人类一致性或绝对正确率。

复核时以`question_id`和`answer_position`对应两份CSV，检查每份完整200行、四项整数范围及原始前五列。每个系统每个上下文各100条，均值分组计算；一致率分母是200条答案，不是400条判断。Excel公式与独立统计相符，保存后的400条分数及依据已逐项核对。

两份报告采用相同表12/13与分析，见[报告检查](../../../verification/2026-10-31/report_aux_evaluation/reports_qa.json)。原始模型成绩、名称恢复结果与本次文本辅助评价分别报告；本样本不涵盖中文自由提问和P0输出。人工评分空表未改。
