# P0开发验收记录

本目录保留冻结Qwen2.5-3B-Instruct的模型文件清单、服务元数据，以及D0规则工具和P0冻结规划在同一V2目录上的20题开发输出。本轮没有更新P0模型权重，不替换原A0/B0实验。

`dev_v1/manifest.json`记录输入与源码哈希、环境、模型调用参数、开始/结束和输入未变检查；`resolved_references.jsonl`为实际解析后的参考，两个`*_predictions.jsonl`保留计划、结构结果、证据、生成和回退；`summary.json`为可复算汇总。题目为程序编写，中英各10题，仅涉及Inception和Interstellar，已用于开发诊断，不能视为独立测试或人工语义评价。

| 指标 | D0 | P0 |
|---|---:|---:|
| 计划匹配 | 12/16 | 7/16 |
| 工具结果匹配 | 8/16 | 7/16 |

| 平均延迟ms | 15.80 | 5954.60 |
| P95延迟ms | 26.30 | 16901.10 |

延迟为逐题串行墙钟时间，排除初始化、未预热，P0包含模型服务与网络开销。结构分数不代表生成句事实或流畅度。P0状态匹配较好，但计划与结构任务匹配较低，不支持全面优于D0的结论。

`frozen_model_manifest.json`为模型资产清单，`model_service.json`为实际服务返回的revision及设备信息。客户端开发manifest中的`revision_verified=false`原样保留；服务元数据另存，不将它伪称为每条响应均独立验证了模型revision。

本机完整依赖回归曾得到`716 passed in 39.21s`；PR前补查Ruff、语法、5000数据校验及离线合成验收通过。工程检查不等于自然语言问答准确率。`reports_qa.json`记录三份最终DOCX的SHA、31页渲染核对、原图和公式保留情况，时间字段及未推送状态为生成该记录时的快照。

尚未完成：独立自然问题测试、人工文本评分、真实终端环境截图及新P0浏览器截图。使用方法见[部署说明](../../../docs/P0冻结语义问答使用说明.md)。
