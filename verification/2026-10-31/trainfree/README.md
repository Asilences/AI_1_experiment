# 无需训练增强：验证材料索引

本目录保存2026-10-31开发的自由提问、范围检查和证据核验实验。历史尝试保留，用于解释代码与结果的来源；报告只采用指定的最终版本，不混合不同知识库、模型或源码快照的指标。

`final`是目录创建时的工作命名，不意味着其永远是最新版本；应结合本索引和每个manifest的实际状态。源码修复来自实现和回归检查，属于开发迭代，本题集也明确作为开发验收集。

## 固定题集与参考答案

- 题集：`benchmarks/trainfree_challenge_v1.jsonl`，SHA256为`a1a6251e447ec4a45b6ebd637d034a7155c95258a14a0e195206dc8e8aab5072`。题目在本轮评估中保持不变。
- 共48题：24道可答、12道不可答、12道需澄清或含未执行条件的题；英文、中文问句各24道。可答题涉及6部电影、四种属性，中文题主要使用英文片名或QID。
- 可答题的目标电影和属性由题集事先声明，答案实体从本次绑定的`entities.json`事实读取。逐题参考事实保存在`resolved_references.jsonl`，没有从模型输出反向生成参考答案。
- 这是程序编写的开发验收集，包含标准问法、改写、别名、混合语言及范围反例；不是独立人工评测，也不是未见电影或任意自然语言泛化的证据。同资产A0复跑核对的24道可答题中，16道所涉电影属于原划分train，8道属于test，不能将整个验收集称为原始test集。
- 本轮四属性为导演P57、类型P136、制作国家P495和原始语言P364。十二属性探索工具属于另一种任务范围，不合并计分。

## 三种系统口径

1. `raw`：仓库现有`Demo.answer_a0`或`Demo.answer_neural`路径，保留其原有中文适配行为。这里的raw并不表示删除仓库已有的所有适配器，也不能和旧训练中仅英文原问句的结果直接混算。
2. `guarded`：冻结原有模型，增加保守问题解析、单一属性检索（神经路径）、证据和答案表面核验；核验不通过即拒答，不通过工具补全答案。
3. `hybrid`：在guarded基础上，对电影、属性和证据均明确的问题，允许确定性知识库查询与完整句模板回退。保留`raw_answer`、`guard`理由和`fallback_used`。工具回退成绩必须标为混合系统，不能称为纯神经生成成绩。

三组均不更新模型权重。神经输入仍受原检索事实数量上限约束；hybrid的完整属性查询是另行标注的工具操作。各运行manifest保存模型、数据、题集和源码哈希及运行环境，最终运行还保存前后校验。

## 指标解释

- `supported_entity_f1`：24道可答题的逐题实体集合F1均值，乘100；`supported_entity_exact`为实体集合完全一致的比例。
- `supported_movie_entity_exact`进一步要求电影实体一致。`supported_movie_relation_entity_exact`还要求输出显式属性字段，原始神经输出可能不提供该字段，不能将这个值当作其普通实体准确率。
- `unanswerable_refusal_accuracy`：12道不可答题最终拒答的比例。
- `clarification_status_accuracy`：12道需澄清子集的**允许状态匹配率**；部分未执行约束题允许保守拒答，因此不等于实际发起澄清的比例。
- `nonanswerable_unsafe_answer_rate`：24道非可答题的自动非拒答作答代理。原始输出按显式`refused`字段或固定拒答句识别，其他措辞的拒答需要人工复核，不能直接将该值称为人工事实错误率。
- `tool_fallback_rate`：工具实际接管最终答案的比例。同资产A0复跑核对中为0，不能把其范围检查收益说成神经模型学到了新能力。
- 延迟为逐题完整调用的墙钟时间；模型初始化另行记录，首次查询成本仍保留，无预热。样本量小且会受本地并行负载影响，不作为稳定吞吐量结论。

所有百分比均使用预先声明的题目数量作为分母，没有按模型最高分重新归一化。具体数字以对应目录的`summary.json`和逐题结果为准；未运行的配置、独立人工评价及显著性分析均不作已完成陈述。

## 复现

本地5000库的A0复跑核对：

```powershell
.\.work\ci-venv\Scripts\python.exe -m kgqa.trainfree_experiment --systems a0 --data-dir data/processed/movies_5000_20261029 --model-path models/pipeline_5000_20261029/model.pkl --output-dir verification/2026-10-31/trainfree/expanded_5000_reproduction
```

相同默认数据和神经资产的六组比较：

```powershell
.\.venv\Scripts\python.exe -m kgqa.trainfree_experiment --systems a0 neural --output-dir verification/2026-10-31/trainfree/reproduction
```

第二条命令的实际知识库、模型和项目根目录以manifest为准；当前主报告的5000运行包在独立工作目录执行，不以主工作区默认1000库替代它。复现必须准备匹配的模型与冻结数据。输出目录必须是新的空目录，程序拒绝覆盖已有结果。

两套5000执行使用相同数据、模型、源码和题集，只用于资产配对与复跑核对，不构成独立数据、统计交叉验证或多种子证据。源码清单的范围限制及事后比对见source_coverage.json。
