# Recorded neural experiment evidence

Recorded completed runs on the frozen 200-movie dataset. Source project paths were converted to project-relative paths; environment/ and model_cache/ indicate the original isolated runtime/cache and are not bundled. Input data are identified by source_manifest hashes; full raw/processed datasets and neural weights are omitted. Numbers and embedded source hash values are unchanged. Derived matched scores use the frozen project score_rows. Only the selected checkpoint is installed locally in ignored model/run directories. Human ratings remain blank.
