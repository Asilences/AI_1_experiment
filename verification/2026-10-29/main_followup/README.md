## 主分支变化与复现范围

PR #5 的双人报告和 200 部电影完整实验已合并，随后 PR #6 增加 5000 部电影扩展程序、独立 A0 训练、界面激活配置与验证摘要。本轮核对了 PR #6 的全部 13 个变更文件、Release 列表和 PR 评论，未发现完整快照或模型附件。清单见 [upstream_audit.json](upstream_audit.json)。

5000 部电影的规模与 A0 分数仍引用该次归档摘要，不作为本轮重新运行的结果。本轮可用的真实冻结数据为 200 部电影、552 个实体、2492 道问答；未重新采集、训练或调整原实验分数。200 部电影与 5000 部电影的结果继续分别保存。

## 已修正的三项问题

1. 独立数据调用 A0 训练而未指定输出目录时，原实现会写入默认模型目录。现在要求明确的 `--output-dir`，避免默认数据与模型错配；默认数据的原训练入口保持可用。
2. 扩展数据续跑原先只核对快照哈希。本轮补充对指定旧划分文件的哈希及划分策略检查；请求与已生成版本不同就停止，避免把旧划分实验误当成本次请求。
3. 基础快照或指定划分文件缺失时，现在在在线候选请求前报错，说明需要恢复哪个输入。新克隆仓库不会先访问网络再发现本地基础数据缺失。

六项新增回归均在旧实现上复现失败，再验证修复。没有覆盖旧模型或实验记录。

## 真实分词器预检

新增 `kgqa.neural_preflight`，按当前神经实现的 384 个输入 token、96 个目标 token 和最多 24 条事实检查数据。训练集使用已知电影，验证与测试使用实际实体链接；指定 `--mapping` 时按 TransE 映射过滤事实。预检读取本地或缓存分词器，不下载模型，不训练，不产生问答分数。

本轮使用 B0 的实际 T5TokenizerFast 与对应映射，结果见 [neural_preflight_200.json](neural_preflight_200.json)：

| 划分 | 问题数 | 输入截断 | 目标截断 | 24 条事实截断 | 目标文本编码损失 |
|---|---:|---:|---:|---:|---:|
| train | 1749 | 0 | 0 | 0 | 51 |
| valid | 373 | 0 | 0 | 0 | 3 |
| test | 370 | 0 | 0 | 0 | 6 |

552 个实体名称中，13 个在分词后再解码时发生变化，均含未知 token。最长训练输入为 299 token，最长目标为 32 token，单电影最多 22 条可用事实；现有 200 部数据无需为截断扩大长度上限。各划分均未发现实体链接错配或保留事实中缺少答案实体。

目标文本损失可能涉及片名或答案名称，不能把这些题目直接计作模型错误。实际 B0 验证预测的 3 道实体集合错误均涉及 `Alfonso Ungría`；本地分词器将该名还原为 `Alfonso Ungra`，与模型输出一致。逐题记录见 [validation_encoding.json](validation_encoding.json)。这是编码瓶颈的具体证据。可被分词器完整表示的名称仍可能生成错误，不能将所有名称错误归于分词器。

复核命令（需要已恢复的配套数据、映射和分词器）：

```powershell
python -m kgqa.neural_preflight --data-dir data/processed --tokenizer runs/B0/checkpoint --mapping models/transe/mapping.json --output output/preflight_200.json
```

检查扩展库的纯文本事实时可将 `--data-dir` 指向其独立目录并省略 `--mapping`；检查结构前缀系统必须提供该版本的配套映射。不要将 200 部电影映射用作 5000 部电影的完整结构表示。输出包含输入、分词器和源码 SHA-256，便于比对版本。
