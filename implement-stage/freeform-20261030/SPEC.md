# 自由问法实现范围

目标：在现有电影问答入口接收更多自然表述，提供可追溯的标准问题转换，以及供下一轮训练使用的独立问句数据。

输入：冻结电影实体、四种关系、现有 A0/神经模型和用户问题。

输出：CLI/网页中的原问题、识别结果、标准问题、答案与证据；另存问句数据和来源说明，不覆盖既有数据、模型或训练目录。

成功命令：`python -m pytest -q tests/test_freeform.py tests/test_freeform_data.py tests/test_web.py`。

Base commit: `b2431f6`。

范围：单电影、单关系；英文自然表述及有限中文问法转成英文问题，答案仍为英文。不增加未知事实、多跳推理或持续对话。当前训练不会自动读入新问句，不在本次运行 GPU 训练。默认实验入口保持不变，网页单独标明自由解析模式。
